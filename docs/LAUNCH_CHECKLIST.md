# NOVARY — production-аудит и launch checklist

27 октября 2026 года. Проверены семь публичных страниц и отдельная `dist/`.
Сайт не опубликован, домен не подключён, Git-коммиты не создавались.
Домен пока не определён пользователем. Артефакт готов к локальной проверке;
домен и настройки выбранного хостинга остаются обязательными шагами запуска.

```text
    ├── js/           # main.js, config.js
    ├── fonts/        # 4 WOFF и 4 лицензии SIL OFL

```

`.git`, `.env`, `.venv`, tests, scripts, docs, previews, node_modules, временные файлы,
внутренние отчёты и hero-a/hero-b исключены allowlist. 12 проверенных закрытых URL
возвращают 404 через сервер `dist/`: [HTTP-проверки](production-exclusions.json).
`dist/` добавлена в `.gitignore`. Предыдущая сборка заменяется; при ошибке уже начатой
сборки частичный результат удаляется. Ошибка входной проверки не разрешает публикацию
старой `dist/`: ориентируйтесь на успешный exit code текущего build.

Из корня `novary-website`:

```bash
python3 scripts/test_build.py
python3 scripts/build.py
python3 scripts/build.py --check
python3 -m http.server 8002 --bind 127.0.0.1 --directory dist
```

Открыть http://127.0.0.1:8002/; остановить Ctrl+C. Сборка — Python 3.10+ и стандартная
библиотека. Node используется для дополнительной проверки JS, когда доступен.
Playwright/Chromium нужны только dev-аудиту; они не требуются посетителю и не входят в dist.

## Обязательные действия перед публикацией

- [ ] Выбрать настоящий публичный HTTPS URL и базовый путь. Задать его локально
  в `NOVARY_SITE_URL`, затем выполнить команды ниже.
- [ ] Проверить сгенерированные canonical/og:url, абсолютные og:image/twitter:image,
  sitemap из семи URL и директиву Sitemap. Без домена этих адресов в текущей сборке нет.
- [ ] Настроить хостинг на публикацию **только dist/** и корректный MIME для модулей JS,
  CSS, SVG и WOFF. Подключение домена и публикация этим аудитом не выполнялись.
- [ ] Настроить HTTPS, редирект HTTP → HTTPS и единый канонический вариант хоста.
- [ ] Применить и проверить HTTP-заголовки: nosniff, Referrer-Policy и CSP.
  Возможная CSP для текущих ресурсов: `default-src 'self'; script-src 'self'; style-src 'self' 'unsafe-inline'; img-src 'self'; font-src 'self'; connect-src 'none'; object-src 'none'; base-uri 'none'; form-action 'none'; frame-ancestors 'none'`.
  Inline style нужен образцам палитры. `frame-ancestors` задаётся HTTP-заголовком.
  Эти заголовки сейчас не заявлены как применённые.
- [ ] Включить HTTP-сжатие и согласовать кэш. Не назначать immutable надолго
  нехешированным main.js/styles.css без стратегии обновления; HTML должен перепроверяться.
- [ ] Если сайт размещён в подпапке, проверить robots именно в корне хоста;
  robots в подпапке не заменяет корневой файл. Инструкция —
  [Google](https://developers.google.com/crawling/docs/robots-txt/create-robots-txt).

```bash
python3 scripts/build.py --site-url "$NOVARY_SITE_URL"
python3 scripts/build.py --check --site-url "$NOVARY_SITE_URL"
```

Шаблон [sitemap.xml.template](sitemap.xml.template) хранится только в docs.
Фиктивных адресов в текущей dist нет. Руководство —
[Google Search Central](https://developers.google.com/search/docs/crawling-indexing/sitemaps/build-sitemap).
