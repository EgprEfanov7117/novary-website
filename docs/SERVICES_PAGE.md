# NOVARY — страница услуг

Отдельная коммерческая страница [services.html](../services.html) продолжает
визуальное направление Digital Architecture. Рабочий адрес — `services.html`;
ранее предложенный `/services/` пока не используется. Дизайн-авторитет остаётся
в [DESIGN_SYSTEM.md](DESIGN_SYSTEM.md), сведения о продукте —
в [PRODUCT.md](../PRODUCT.md).

## Состав страницы

- Собственный hero с точным заголовком «Цифровые решения для вашего бизнеса.»
  и индексом направлений 01–04, как запрошено пользователем.
- Лендинги, корпоративные сайты, веб-приложения и AI-решения: для каждого есть
  описание, задачи бизнеса, возможные функции и отдельный CTA к `#contact`.
- Четыре этапа: обсуждение задачи, проектирование, разработка, тестирование
  и запуск. Для каждого указан результат.
- Шесть вопросов о выборе формата, стоимости, сроках, работе без ТЗ,
  расширении функций и уместности AI.
- Финальный заголовок «Есть идея? Давайте обсудим.» и переход в Telegram.

Функции обозначены как возможный состав проекта, который согласуется после
обсуждения. Цены, сроки, гарантии и коммерческие результаты не выдуманы.
Формы и аналитика на этой странице не подключены.

## Реализация и связи

[services.css](../assets/css/services.css) задаёт только композицию новой страницы.
Она подключает существующие [styles.css](../assets/css/styles.css) и
[main.js](../assets/js/main.js) без изменений; переиспользованы шапка, футер,
мобильное меню, FAQ и компоненты этапов работы. Хлебные крошки и ссылки на
проекты, студию и контакты возвращают к соответствующим разделам главной.
Текущая страница отмечена через `aria-current="page"`.

Hero и секции главной сохранены побайтово. Изменения в существующих HTML
ограничены ссылками «Услуги»: три в `index.html`, по две в `hero-a.html`
и `hero-b.html`. Они теперь ведут на `services.html`.

На широком экране вводный текст и индекс, затем описание услуги и её состав
расположены в двух колонках. До 768 px они складываются в одну колонку;
до 480 px индекс становится списком. FAQ использует нативные `details` /
`summary`; навигация и содержание доступны без JavaScript. Общий скрипт
управляет меню и переносом фокуса при переходах по локальным якорям.
Режим reduced motion отключает появление индекса и плавную прокрутку.

## Telegram

Общая настройка в [config.js](../assets/js/config.js):

```js
export const TELEGRAM_BOT_URL = "https://t.me/novary_studio_bot";
```

Адрес предоставлен пользователем и применяется ко всем контактным ссылкам
через общий `main.js`. Публичный URL не является секретом; токен бота в сайт
не переносится. Без JavaScript или при некорректной настройке ссылка ведёт
к уведомлению о временной недоступности канала.

## Проверка и превью

Из корня `novary-website`:

```bash
python3 scripts/check_site.py
python3 scripts/check_hero_concepts.py
python3 scripts/check_services.py
node --check assets/js/config.js
node --check assets/js/main.js
```

Все команды прошли. [check_services.py](../scripts/check_services.py) проверяет
ресурсы, ссылки между страницами, якоря, уникальность ID, ARIA, метаданные
и базовые ограничения анимации; обычный запуск не требует временного baseline.

[Браузерный отчёт](services-checks.json): 70 успешных проверок, без ошибок
и провалов. Проверены 13 ширин от 320 до 1920 px, увеличение текста до 200%,
меню и его фокус, клавиатура, FAQ, локальные якоря, переходы между страницами,
режимы без JavaScript и reduced motion. Проверены подстановка действительного
Telegram URL и резервное состояние с тестовой подменой настройки.
Внешний Telegram не открывался, бот не запускался, сообщения не отправлялись.

Полные снимки из браузера:

- [Desktop — 1440 × 5029](../previews/services-desktop.webp).
- [Mobile — 390 × 7096](../previews/services-mobile.webp).

Происхождение снимков записано во встроенных XMP-метаданных. Независимый
финальный просмотр не выявил существенных замечаний. Impeccable CLI был
недоступен; проверки детектором, сертификация доступности, проверка экранным
диктором и межбраузерная сертификация не заявляются. Публикация и Git-коммиты
не выполнялись.
