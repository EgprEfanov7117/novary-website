# Страница контактов NOVARY

`contact.html` продолжает существующее направление Digital Architecture.
Источник визуальных правил — `DESIGN_SYSTEM.md` и общий `assets/css/styles.css`.
Исходные документы проектирования сохранены; новая дизайн-система не создавалась.
Существующее расхождение документации и реализации отдельно не исправлялось.

## Состав и поведение

- Общая шапка, мобильный `dialog`, футер, кнопки и FAQ переиспользованы.
- Hero: «Давайте обсудим ваш проект.» и согласованный текст о задаче бизнеса.
- Широкая синяя кнопка «Написать в Telegram» — главный акцент первого экрана.
- На desktop рядом небольшая SVG-схема «Из разговора — в проект».
- Три пронумерованные подсказки: продукт, задача, пожелания; подробное ТЗ не нужно.
- Три шага первого обсуждения: сообщение, уточнение задачи, возможное решение.
- Пять нативных `details` / `summary`; первый ответ открыт изначально.
- Финальный блок «Начнём с вашей идеи.» с CTA «Обсудить проект».

Композиция изолирована в `assets/css/contact.css`; общие CSS, `main.js`
и `config.js` не изменены. Сохранены палитра, локальные шрифты и контейнер.
На узких экранах схема скрыта, блоки переходят в одну колонку.
Схема появляется один раз за 450 мс; при reduced motion анимация отсутствует.
Новых фотографий, библиотек, форм и альтернативных каналов связи нет.

Три Telegram-ссылки используют прежнюю единую настройку
`https://t.me/novary_studio_bot` в `assets/js/config.js` и общий `main.js`.
При некорректной настройке или без JavaScript остаётся сообщение о недоступности.
Новый адрес и дублирующая конфигурация не добавлялись.

## Маршруты и сохранность

Все пять основных страниц существуют: главная, услуги, проекты, студия, контакты.
В восьми прежних HTML изменены только 16 ссылок с подписью «Контакты»:
на `contact.html`, а из вложенных кейсов — на `../contact.html`.
Прежние hero, основное содержимое, CTA, Telegram-ссылки и ресурсы сохранены.
Снимок SHA-256 81 прежнего файла: `/private/tmp/novary-contact-before/manifest.json`.
README, PRODUCT и CREDITS обновлены только для текущего объёма и источников.

## Запуск и проверки

```bash
python3 -m http.server 8001 --bind 127.0.0.1 --directory /Users/egor/Desktop/NOVARY/novary-website
```

Открыть `http://127.0.0.1:8001/contact.html`; остановить сервер через `Ctrl+C`.
Проверка из корня проекта без внешних зависимостей:

```bash
python3 scripts/check_contact.py
python3 scripts/check_contact.py --baseline /private/tmp/novary-contact-before/manifest.json --allow-changed README.md --allow-changed PRODUCT.md --allow-changed CREDITS.md
```

Все шесть Python-проверок из README и `node --check` для `main.js`/`config.js` прошли.
[Браузерный отчёт](contact-checks.json): 83 успешных проверки, 0 сбоев, 0 ошибок.
Проверены 13 ширин от 320 до 1920 px; главный CTA виден в первом экране на каждой.
Проверены текст 200% при 390/1440 px, меню, фокус, Escape и клавиатура.
FAQ проверен мышью, клавиатурой, без JS и со всеми открытыми ответами без переполнения.
Проверены входящие ссылки с восьми страниц и исходящая навигация контактов.
Три Telegram CTA нажаты с локальным перехватом открываемых окон: бот не запускался,
сообщения не отправлялись. Проверены неверная настройка, no-JS и reduced motion.
HEAD публичного URL бота вернул 200; это не проверка обработки сообщений ботом.
